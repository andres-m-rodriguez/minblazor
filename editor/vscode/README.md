# minblazor (VS Code)

Component IntelliSense for [minblazor](https://github.com/andres-m-rodriguez/minblazor)
`.razor` files. Launches the `minblazor-lsp` language server (bundled) and offers
completion for the components available to a file — the sibling `.razor` files plus any
virtual components contributed by `Build.cs`.

Type `<` in a `.razor` file to see the available components.
